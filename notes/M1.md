# M1 notes for the teammate: project setup, models, config loading

1. **Setup:** `student/` is the git repo; `uv sync` builds the environment from `pyproject.toml` and `uv.lock` (Python 3.10 only). Run everything with `uv run ...`.
2. **The grader's schema** (`StepMetrics`, `SolutionOutput`, `MBPPTaskInput`, ...) lives in `agent_smith/models_public.py`, copied unchanged from `../moulinette/models_public.py`. Never edit it. Our own changes go in `agent_smith/models.py`.
3. **Pydantic models are forms with typed boxes.** `Model(...)` or `Model.model_validate_json(text)` checks every box and converts what it safely can (`"256"` becomes `256`). Wrong values raise `ValidationError`. Unknown keys are ignored for these models.
4. **`load_json_model(path, ModelClass)`** in `agent_smith/config.py` reads a JSON file and returns the model, or raises `ConfigError` with a one-line message (missing file, invalid JSON, wrong type).
5. **Tests:** `uv run pytest -q` should show 8 passed. A test is a function that fails if anything inside it raises an error (`assert` raises when false; `pytest.raises` expects an error).
